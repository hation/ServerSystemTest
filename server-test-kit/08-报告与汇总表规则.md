# 08 · 报告与汇总表规则（模板）

> 目的：统一评测报告的**固定章节契约、入表流程、失败处理、单元格写法、下游产物边界、索引登记与汇总表结构**，保证报告可被入表脚本稳定解析、跨批次可累计。通用版（去业务化），供服务器整机测试项目套用。
> 状态：[当前有效]（2026-11-13）
> 变更记录：2026-11-13 新建（由 disk-tests 38 号 §八 + report_to_excel.py 机制 + 39 号索引登记规则泛化）

## 1. 报告固定章节契约

- 报告必须包含**三张固定表**：总览表、明细表、异常清单表。
- 三张表所在章节标题关键词**可配置**（默认示例：`总览` / `明细` / `异常`），配置见入表脚本（report_to_excel 配置段）；示例章节：`## 0. 总览（判定汇总）`、`## 1. 逐实体明细`、`## 3. 异常/复核标记`。
- **章节内不得再用同级（`##`）标题切分**（可用 `###`），否则表格会落到章节之外、被脚本漏读。
- **列名必须与入表脚本配置一致**：缺列可少、但不得改名/加列；列名逐字一致，脚本解析依赖固定表头。表头列名用 `{列名}` 占位符，由新项目按本号文档与 report_to_excel 配置定（示例列名：唯一键 / 型号 / 出厂日期 / 通电时间 / 判定——按部件替换）。

## 2. 入表流程（每次必做）

1. **dry-run 先核对**：`python scripts/report_to_excel.py docs/<新报告>.md --dry-run`
   - 输出：该报告批次、实体数、各判定等级数量；
   - **核对批次 / 实体数 / 🔴🟡🟢⚠️ 计数与报告一致后再入表**；有任何「已忽略列」都说明表头不合规，先修报告。
2. **正式入表**：`python scripts/report_to_excel.py docs/<新报告>.md`
3. **幂等**：同一份报告重跑不会重复（以报告文件为幂等键），只替换它自己的行；**不同批次追加历史行**。
4. **多批次报告全量入表**：一份报告含多个批次时脚本会全量入表，无需拆分报告。
5. 向用户汇报脚本输出原文：`已写入 docs/{汇总文件名}.xlsx：总览 N 行 / 明细 N 行 / 异常 N 条 / 批次 N 个`；重跑时说明是重跑。

## 3. 失败处理（退出码）

- **退出码 2** = 报告缺「总览」表，或表头不含 `唯一键`/`判定`，或报告文件不存在/未给参数 → **修报告后重跑，禁止跳过**。
- **退出码 3** = 环境缺依赖（如 openpyxl）→ `pip install openpyxl`（按提示安装依赖后重跑）。

> 退出码以入表脚本为准（0 = 成功；2 = 报告缺必需的表或表头；3 = 环境缺依赖），新项目保持一致。

## 4. 单元格写法契约

- **复合单元格拆分**：含 `/` 的复合值拆两列（示例：`2.66MB / 26.88MB` 拆为"读/写"两列）；非两段的值不拆分。
- **判定列必须以 🔴/🟡/🟢/⚠️ 开头**；裸 `⚠` 也识别为 `⚠️`；判定等级只认这四个 emoji，其余一律记作「—」。
- **数值单位固定**：时长 `32.5 h`；容量自动换算到统一单位（KB/MB/GB/TB 系数固定）；整数去千分位逗号（示例：`5,165` → 5165）。
- 脚本会剥离 Markdown 加粗/行内反引号，但正文以不写为佳。

## 5. Excel 是报告的下游产物

- **不手工改 Excel**：Excel 由入表脚本从报告解析生成，任何数据修正只改报告再重跑。
- **要改数据就改报告再重跑**；历史回填用 `--backfill <范围>`（示例：旧格式报告无固定表格不入表；复查报告因结构为增量对比、无规范明细列，技术字段留空属正常，总览行完整，不算不合规）。

## 6. 索引登记规则

- **报告编号唯一递增**：`NN-` 前缀按创建顺序递增；新报告编号从当前最大 +1 起（索引文档为唯一固定编号例外，只更新内容、不递增编号）。
- **索引三处登记**：一份新报告完成后，在**索引文档 / 汇总表 / 触发词表**三处登记（示例：索引文档的型号→报告映射 / 批次→报告映射 / 唯一键→报告映射各节；触发词表"登记索引"入口的产物列）。
- **防重复**：每批数据生成报告前先查索引，确认"型号 + 唯一键"是否已评估过；已评估 → 只做增量对比/复查，注明"该唯一键此前已在 NN 号报告评估"，不重复写完整结论；唯一键是新的 → 正常新增评估。
- **登记脚本参数化**：索引登记用参数化脚本（示例：`register_index.py --number N --data <文件>`），不手工改索引。

## 7. 汇总表结构模板（四 sheet，可配置）

| sheet | 内容 | 示例列 |
| --- | --- | --- |
| 总览 | 全部实体逐行判定 | {唯一键} / {型号} / {出厂/批次信息} / {通电/使用时长} / {判定} |
| 明细 | 逐实体技术字段 | {唯一键} / {技术字段1..N} |
| 批次汇总 | 每批次一行：实体数、各判定计数 | {批次} / {实体数} / {🔴🟡🟢⚠️ 计数} |
| 异常清单 | 异常/复核标记逐条 | {唯一键} / {标记} / {说明} |

> sheet 名称与列名**可配置**（默认示例：总览 / 明细 / 批次汇总 / 异常清单），以入表脚本配置为准；新增 sheet 需同步改脚本配置与本文档。
