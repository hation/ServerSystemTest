# 功能与命令指引

offline-stress-pkg 一键压测工具速查：CPU/内存/硬盘压测 + 自动挂载 + 自动复盘，全部命令可直接复制执行。

## 1. 功能速查表

| 功能 | 菜单数字 | 命令行命令 | 说明 |
| --- | --- | --- | --- |
| 进入交互菜单 | — | `sudo bash oneclick.sh` | 无参数弹出菜单（1-8、0） |
| 全测（CPU+内存+每块数据盘+系统盘） | 1 | `sudo bash oneclick.sh all` | 默认 10h |
| 测 CPU+内存（排除硬盘） | 2 | `sudo bash oneclick.sh all --no-hdd` | 不测任何盘、跳过挂载 |
| 只测数据盘 | 3 | `sudo bash oneclick.sh hdd` | 每个 /mnt/HDD* 一个任务 |
| 只测系统盘 | 4 | `sudo bash oneclick.sh sysdisk` | 仅系统盘 |
| 只测 CPU | 5 | `sudo bash oneclick.sh cpu` | 仅 CPU worker |
| 只测内存 | 6 | `sudo bash oneclick.sh mem` | 按内存条根数压 |
| 查看最近批次状态 | 7 | `sudo bash oneclick.sh status` | 最近批次启动状态 |
| 复盘并生成汇总 | 8 | `sudo bash oneclick.sh review` | 对最近批次逐个复盘 |
| 查看帮助 | — | `sudo bash oneclick.sh --help` | 打印完整用法 |

## 2. 参数选项表

| 选项 | 说明 |
| --- | --- |
| `--timeout <时长>` | 所有任务统一超时，默认 10h（数字 + 可选 d/h/m/s，如 `10h`、`30m`、`8h`） |
| `--no-hdd` | 仅 all 生效：排除所有硬盘（数据盘+系统盘），只测 CPU+内存；与 `--rebuild` 互斥 |
| `--rebuild` | 重新分区并格式化数据盘（会清空数据盘，慎用；仅 all/hdd 生效） |
| `--quiet` | 终端不打印实际执行命令（命令仍写入批次目录） |

## 3. 典型场景示例

```bash
# 新机全测（默认 10h）：CPU+内存组合 + 每块数据盘 + 系统盘
sudo bash oneclick.sh all

# 只关心 CPU+内存、不想压盘（跳过挂载）
sudo bash oneclick.sh all --no-hdd

# 快速内存测试 30 分钟
sudo bash oneclick.sh mem --timeout 30m

# 新机全测并重建数据盘（会清空数据盘数据，慎用）
sudo bash oneclick.sh all --rebuild

# 压测结束后复盘最近批次
sudo bash oneclick.sh review

# 查看最近批次状态
sudo bash oneclick.sh status
```

## 4. 使用前提

- root 权限（sudo）；先执行 `sudo bash install.sh` 安装依赖（stress + dmidecode），可选 `sudo bash verify.sh` 校验安装
- 数据盘挂载：all/hdd 模式启动时自动挂载；`--no-hdd` 跳过挂载
- 无图形环境（SSH、无 DISPLAY）自动降级为后台并行执行，输出写入批次目录 `<任务>.out`

## 5. 注意事项 / FAQ

- `--rebuild` 会清空数据盘数据，在菜单中（项 1/3）需输入 `y` 才重建；默认复用数据盘已有文件系统
- `--no-hdd` 仅支持 all 模式；与 `--rebuild` 互斥（同时使用会报错退出）
- **数字参数不能作为命令行参数**：`sudo bash oneclick.sh 1` 会报"未知参数：1"并打印帮助；数字（1-8、0）只在进入菜单后输入
- 批次结束自动逐任务复盘，汇总在批次目录 `summary.txt`；存在异常结论（或启动失败/挂载异常）时批次退出码 1
- 选项与模式顺序灵活：`all --timeout 30m` 与 `--timeout 30m all` 等价；只带选项不带模式会进菜单（选项仍生效；`--no-hdd` 除外——它仅支持 all 模式，单独使用会直接报错）
