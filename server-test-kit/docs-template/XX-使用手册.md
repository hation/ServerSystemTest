## 1. 快速开始（一条命令）

```powershell
# 一键跑通（识别建档 → 全量压测 → 出报告；按新项目入口替换）
cd <部署目录>
.\scripts\run_<project>.ps1 -BatchName batch01 -DryRun   # 先预览
.\scripts\run_<project>.ps1 -BatchName batch01 -Yes       # 确认后执行
```

> 第一次使用先走一次「真机冒烟」（见 XX-部署清单 §7），跑通链路后再正式开测。

## 2. 常用命令

> 通用防呆参数（两项目实证，新项目保留同名约定）：

| 参数 | 含义 | 示例 |
| --- | --- | --- |
| `-DryRun` | **只预览**命令/计划清单，不执行任何操作（推荐先跑） | `run_<project>.ps1 -DryRun` |
| `-Yes` | **跳过二次确认**（仅用于明确要执行的场景；破坏性操作必须确认） | `run_<project>.ps1 -Yes` |
| `-BatchName <批次>` | 指定批次（不传则自动生成 `B+日期+时间`） | `-BatchName B20261113` |
| `-ParseOnly` | 只解析已有原始日志（断点续测） | `-ParseOnly -LogFile .\results\raw\batch01.log` |

其他常用命令（按新项目实际脚本替换）：

```powershell
# 环境自检 / 带外链路自检 / 能力评估（三步走，见 10 号文档 §6）
.\scripts\check_env.ps1
.\scripts\diag_oob.ps1 -BmcHost <IP> -BmcUser <user>
.\scripts\assess_capability.ps1 -Local -MachineName <被测机>   # 评估被测机须在机内跑

# 识别建档
.\scripts\identify_<entity>.ps1 -BatchName batch01
```

## 3. 输出目录结构

```text
results\（默认，可用参数重定向）
├── <批次>-inventory.csv      # 识别建档（唯一键 + 识别字段 + 预期清单比对）
├── <批次>-report.csv         # 单批逐台 pass/fail
├── master_manifest.csv       # 累计总表（跨批次按唯一键追踪）
├── raw\                      # 原始日志（如 SOL 抓流 mtlog）
├── reports\                  # 汇总报告
└── assessment\               # 能力评估（<机器名>-cap.csv / -assessment.csv / -assessment.txt）
```

> 结果只产生在**运行编排器那台机器**（10 号文档 §7）；字段说明见 08 号报告与汇总表规则。

## 4. 配置

编辑 `conf\app.conf`（键值注释格式）：抽样比例、判据达标线（引用 10 号文档 §4 判据定值表）、并发数、BMC 默认参数等。**修改即生效，无需重启、无需重制引导介质**；命令行显式参数优先于配置。

## 5. 注意事项

1. **防呆**：自动排除高危目标（示例：系统盘/生产在用机），测试前打印目标清单需人工确认；高危操作强确认 + `-DryRun`。
2. **只读保证**：采集/识别类命令清单不得含任何写操作（源项目无写命令【示例】，新项目按被测对象核对）；`-DryRun` 可预览核对命令清单。
3. **破坏性操作确认**：压测含写操作会覆盖数据（如磁盘写压测）、断电循环会重启被测机——必须用户明确确认后才执行，不得仅凭触发词直接执行（07 号工作流规则 §1.3）。
4. **关键顺序**：**必须先启动编排器（开 SOL 抓流）再引导被测机**；顺序反了等于白测（10 号文档 §7）。
5. **断点续跑**：长耗时测试每阶段落标记，中断后重跑自动跳过已完成阶段。
6. **指令记录**：所有脚本自动写入 `results\cmdlog\commands-<日期>.csv`（密码打码），排查历史操作先看这里。

## 6. 常见问题

| 问题 | 解答 |
| --- | --- |
| 跑完一轮没看到日志/结果？ | 结果只产生在编排机的 `results\`；确认是否**先启动编排器再引导被测机**（顺序反了等于白测）。 |
| 控制台报「禁止运行脚本」？ | 用 `powershell -NoProfile -ExecutionPolicy Bypass -File` 形式运行（不改系统策略）。 |
| 找不到 `.\scripts\`？ | 命令必须从统一部署目录（示例：`C:\server-tests`）下执行（相对路径）。 |
| 带内项读不到被测机？ | 带内项读的是"运行脚本那台机器"——识别/评估被测机必须在**被测机本机**跑。 |
| 判据/阈值怎么定？ | 全部来自 10 号文档 §4 判据定值表（按客户定值），本手册不写死数值。 |
