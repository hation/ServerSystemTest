# 服务器综合压力测试报告（7380 · stress-test-4-1）

| 项目 | 内容 |
|---|---|
| 报告编号 | STRESS-7380-ST4-1-20261114 |
| 设备标识 | stress-test-4-1（数据目录 `tmp/stress-test-4-1`） |
| 测试机型 | Hygon C86-3G 7380 32-core（2 路，128 逻辑线程） |
| 测试类型 | CPU / 内存 / 磁盘 组合负载长稳测试 |
| 测试时间 | 2026-11-14 13:41:01 — 2026-11-14 23:42:49（10 小时） |
| 内存总量 | 1,120.7 GiB |
| 结论 | **有条件通过（OK_LIMITED）**：稳定性通过；覆盖超测、内存差 2G 未达门槛 |

## 1. 测试目的

验证该机在 CPU、内存、6 块 NVMe 数据盘与系统盘同时加压的条件下，连续运行 10 小时的稳定性。

## 2. 测试环境

| 项目 | 配置 |
|---|---|
| 机型 | 7380（Hygon C86-3G 32-core） |
| 内存 | 1,120.7 GiB |
| 系统盘 | `/dev/mapper/klas-root`，392 GB，XFS，挂载 `/` |
| 数据盘 | 6 × 7.0 TB NVMe：`nvme0n1→/mnt/HDD01`、`nvme5n1→HDD02`、`nvme1n1→HDD03`、`nvme2n1→HDD04`、`nvme3n1→HDD05`、`nvme4n1→HDD06` |
| 测试前占用 | 系统盘 11G（3%）；数据盘均 28K（1%） |

## 3. 测试方法

10 个任务在 13:41:01 — 13:42:30（89 秒）内启动，全程并发运行 10 小时：

| 负载 | 命令 | 目标 |
|---|---|---|
| 磁盘 × 7 | `stress --hdd 1 --hdd-bytes 10G --timeout 10h` | 数据盘（6 块） |
| 磁盘 × 1 | 同上 | 系统盘 `/stresstest-hdd` |
| CPU × 1 | `stress --cpu 110 --timeout 10h` | 110 线程 |
| 内存 × 1 | `stress --vm 16 --vm-bytes 54G --timeout 10h` | 目标 864G |

判定闸门：B 运行完整性、C 指标口径、D 覆盖完整性、E 负载达成（CPU ≥90%、写非零 ≥70%、内存峰值 ≥691G）。

## 4. 测试结果

### 4.1 执行结果

| 项目 | 结果 |
|---|---|
| 批次目录 | 10 个（8 个 hdd + 1 cpu + 1 mem） |
| 采样行数 | 每批次 1191 行 |
| 退出码 | 10/10 为 `0` |
| 收尾行 | 10/10 有 `successful run completed` 级记录 |
| 错误日志 | 仅收尾结论行，无报错正文 |

### 4.2 资源指标（整机口径）

| 指标 | 实测 | 判定 |
|---|---|---|
| CPU 使用率 | 99.8% — 100.0% | 达标 |
| 内存峰值 | **689 GB**（目标 864G 的 79.7%） | **未达标**（门槛 691G，差 2G） |
| swap | 全程 0 | 达标 |
| 整机写吞吐均值 | 1424 — 1429 MB/s | — |
| 写为 0 的窗口 | 0 / 1191 | 达标 |

### 4.3 稳定性

10 个任务全部正常结束，无 stderr 输出、无 OOM、无 swap、无重启、无性能衰减。

### 4.4 磁盘覆盖

| 项目 | 结果 |
|---|---|
| 已挂载数据盘 | 6 块 |
| 数据盘任务数 | **7 个** |
| 系统盘任务 | 1 个 |
| 判定 | **超测**（任务数 > 盘数，多出的任务与某块盘共用或写向未挂载目录） |

按规则，超测须判 `OK_LIMITED`，并检查根分区已用增量以判断是否有任务写入系统盘。本批次根分区起始已用 11G，未采集结束时的 `info-after`，该项标"不可判定"。

## 5. 测试结论

1. **稳定性：通过。** 组合负载 10 小时，10 个任务全部 `exitcode=0`，无故障。
2. **CPU：通过。** 99.8%~100%。
3. **磁盘：通过。** 写非零窗口 100%，均值约 1425 MB/s。
4. **内存：未达标。** 峰值 689G，为目标值的 79.7%，低于 80% 门槛（691G），差 2G。
5. **覆盖：受限。** 7 个数据盘任务对 6 块盘，属超测。

**综合判定：有条件通过（OK_LIMITED）。** 稳定性结论成立；负载达成与覆盖两项受限。

## 6. 适用范围

- 可表述："组合负载下整机 10 小时稳定，无异常退出与 I/O 报错"；
- 不可表述："内存压测通过"（相差 2G 未达门槛）、"6 块盘均已覆盖"（7 任务对 6 盘）、"单盘带宽达标"。

## 7. 问题与建议

| 问题 | 建议 |
|---|---|
| 数据盘任务数（7）多于盘数（6） | 启动前按实际挂载清单生成任务，避免超测 |
| 内存峰值 79.7%，处于门槛边缘 | 按机型计算内存目标，或采用保持型分配 |
| 未采集 `info-after` | 结束后补采，便于核对根分区增量 |
| 监控为整机汇总 | 增加按设备统计 |
