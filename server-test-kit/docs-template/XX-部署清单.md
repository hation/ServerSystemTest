## 1. 环境

- [ ] 编排机操作系统版本满足要求（示例：Windows 10 / Server 2016+）
- [ ] PowerShell 5.1+（`$PSVersionTable.PSVersion` 确认）
- [ ] 统一部署目录已就位（示例：`C:\server-tests`），所有命令从该目录运行
- [ ] 被测机平台/OS 范围与方案一致（示例：Windows Server / Linux）

## 2. 权限

- [ ] 编排机：管理员权限（读底层数据/挂载介质需提权）
- [ ] 被测机：管理员/root 权限（带内识别与压测需要）
- [ ] BMC 账号可登录（IP/用户名/密码；密码运行中提示输入，不落盘）
- [ ] 网络：编排机 ↔ BMC 管理口可达；被测机业务网连通

## 3. 工具

- [ ] 内置工具齐全（示例：ipmitool / Memtest86+ / Prime95 / smartctl / fio / iperf——按 10 号文档 §2 选型表核对）
- [ ] 未随包工具已配好（示例：HWiNFO、Linux 的 stress-ng / mcelog / edac-utils——按 10 号文档 §8 校验表）
- [ ] 关键脚本齐全（示例：check_env / diag_oob / assess_capability / identify / run_<project>）
- [ ] `check_env.ps1` 输出**全部 OK**（6 项示例：PowerShell、脚本、ipmitool、ISO、配置模板、历史库可选）

## 4. 依赖

- [ ] 历史库（可选）：Python 3 就位，SQLite 库可初始化
- [ ] 引导介质（可选）：Memtest86+ ISO / 菜单版 ISO 已构建并校验
- [ ] 第三方依赖（示例：GRUB 等构建工具）已入库或随包

## 5. 带外配置

- [ ] `diag_oob.ps1` 四步通过：`mc info` / `chassis status` / `sdr elist` / `sol activate` 短探测无 Error
- [ ] BMC 已开启 SOL；**BIOS 串口重定向已配置（115200）**
- [ ] 虚拟介质（可选）：BMC 远程挂载功能可用（全自动批量推荐）

## 6. 离线包校验

- [ ] 离线包由单源构建生成（build.ps1），无手工双目录（版本单一来源 VERSION）
- [ ] 版本号确认是最新版（拷贝到目标环境后核对）
- [ ] 离线包完整性校验通过（示例：哈希比对）；免安装免联网，拷贝即用

## 7. 真机冒烟

- [ ] 真机冒烟通过：1 台被测机跑通「识别建档 → 1 轮快测 → 出报告」全链路（先 `-DryRun` 预览）
- [ ] 冒烟确认**先启动编排器再引导被测机**的顺序约定（结果可抓到、可判读）
- [ ] 冒烟产物落盘可追溯（`results\` 下原始日志 + 报告 + 总表齐全）

> 全部勾完 → 进入正式测试（按 01-测试方案 §7 阶段 0–6）。
