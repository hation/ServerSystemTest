## Step 1：新建 `offline-stress-pkg/usb-eject.sh`

- 风格与 `mount-iso.sh` 一致：不 `set -e`、中文输出、测试接缝（DRY_RUN / SKIP_ROOT_CHECK / LSBLK_BIN / MOUNT_LOG / POWEROFF_BIN）
- 参数解析：`--poweroff`、`--disk <name>`、`-h/--help`
- 设备检测：`lsblk -P -o NAME,SIZE,TYPE,TRAN,MOUNTPOINT` 取 `TYPE=="disk" && TRAN=="usb"`（-P 键值解析，不依赖列号）
- 选盘：单盘自动；多盘列表 + 输入序号/盘名；`--disk` 校验确为 USB 盘否则 exit 1
- 卸载：收集该盘及子分区的所有非空 `MOUNTPOINT`（含 `/run/media/...`），先子后盘逐个 `umount`；DRY_RUN 只打印
- 失败处理：提示 `fuser -vm <mp>` / `lsof +f -- <mp>`（命令存在才提示），写日志，exit 1
- 验证：重新读取确认该盘所有挂载点为空
- `--poweroff`：`$POWEROFF_BIN power-off -b /dev/<disk>`，失败回退 `eject /dev/<disk>`，均失败仅警告
- 系统盘保护：`df /` 命中该盘则拒绝
- 日志：每步写 `$MOUNT_LOG`
