# 服务器综合压力测试报告（7380 · stress-test-3-1）

| 项目 | 内容 |
|---|---|
| 报告编号 | STRESS-7380-ST3-1-20261114 |
| 设备标识 | stress-test-3-1（数据目录 `tmp/stress-test-3-1`） |
| 测试机型 | Hygon C86-3G 7380 32-core（2 路，128 逻辑线程） |
| 测试类型 | CPU / 内存 / 磁盘 组合负载长稳测试 |
| 测试时间 | 2026-11-14 12:49:35 — 2026-11-14 22:57:54（10 小时） |
| 内存总量 | 1,120.7 GiB |
| 结论 | **通过（OK）**，覆盖项为"不可判定"（见第 4.4 节） |

## 1. 测试目的

验证该机在 CPU、内存、6 块 NVMe 数据盘与系统盘同时加压的条件下，连续运行 10 小时是否出现宕机、异常退出、内存溢出、I/O 错误或性能衰减。

## 2. 测试环境

| 项目 | 配置 |
|---|---|
| 机型 | 7380（Hygon C86-3G 32-core） |
| 内存 | 1,120.7 GiB |
| 系统盘 | `/dev/mapper/klas-root`，392 GB，XFS，挂载 `/` |
| 数据盘 | 6 × 7.0 TB NVMe：`nvme1n1→/mnt/HDD01`、`nvme4n1→HDD02`、`nvme5n1→HDD03`、`nvme3n1→HDD04`、`nvme0n1→HDD05`、`nvme2n1→HDD06` |
| 测试前占用 | 系统盘 11G（3%）；6 块数据盘均为 28K（1%） |
| 压测工具 | stress + `stress-test.sh`，采样间隔 30 秒 |

## 3. 测试方法

9 个任务在 12:49:35 — 12:57:38 之间启动，全程并发运行 10 小时：

| 负载 | 命令 | 目标 |
|---|---|---|
| 磁盘 × 6 | `stress --hdd 1 --hdd-bytes 10G --timeout 10h` | 6 块数据盘（每任务一个挂载点） |
| 磁盘 × 1 | 同上 | 系统盘 `/stresstest-hdd` |
| CPU × 1 | `stress --cpu 110 --timeout 10h` | 110 个计算线程 |
| 内存 × 1 | `stress --vm 16 --vm-bytes 54G --timeout 10h` | 16 × 54G = 864G |

判定闸门：B 运行完整性、C 指标口径、D 覆盖完整性、E 负载达成（CPU ≥90%、写非零窗口 ≥70%、内存峰值 ≥ 目标 80% 即 691G）。

## 4. 测试结果

### 4.1 执行结果

| 项目 | 结果 |
|---|---|
| 批次目录 | 9 个（7 个 hdd + 1 cpu + 1 mem） |
| 采样行数 | 每个批次均 1191 行（10 小时，30 秒间隔） |
| 退出码 | 9/9 为 `0` |
| 收尾行 | 9/9 出现 `successful run completed in 36000s` 级记录 |
| 错误日志 | 全部为收尾结论行，无报错正文 |

### 4.2 资源指标（整机口径）

| 指标 | 实测 | 判定 |
|---|---|---|
| CPU 使用率 | 98.7% — 100.0% | 达标 |
| load | 与 128 线程满载相符 | 达标 |
| 内存峰值 | **710 GB**（目标 864G 的 82.2%） | 达标（≥691G） |
| swap | 全程 0 | 达标 |
| 整机写吞吐均值 | 1464 — 1477 MB/s | — |
| 写为 0 的窗口 | 最多 10 / 1191（0.8%） | 达标（非零 ≥70%） |

### 4.3 稳定性

无异常退出、无 stderr 输出、无 OOM、无 swap 抖动、无重启；末段指标与中段一致，未发现衰减。

### 4.4 磁盘覆盖

| 项目 | 结果 |
|---|---|
| 已挂载数据盘 | 6 块 |
| 数据盘任务数 | 6 个 |
| 系统盘任务 | 1 个 |
| 结论 | 数量相等，但**无逐盘证据**（`run-config` 不含测试目录，日志名为循环序号） |

按判定规则，数量相等但无法逐盘对应时，覆盖列记 **"不可判定"**，不得表述为"6 块盘全部已覆盖"。数量与配置吻合，可视为"很可能完整"，但缺乏可审计证据。

## 5. 测试结论

1. 组合负载连续运行 10 小时，9 个任务全部正常结束，整机无故障。
2. CPU 满载达标；内存峰值 710G（82.2%）达标；磁盘持续写入，无空跑。
3. 覆盖数量与盘数一致，但缺逐盘证据，覆盖列为"不可判定"。

**综合判定：通过（OK）。**

## 6. 适用范围

- 仅说明"组合负载下整机稳定"，不代表 CPU / 内存 / 磁盘单项性能上限；
- 磁盘指标为整机汇总，**不代表单盘顺序写带宽**（6 盘并发，且含系统盘与分区、逻辑卷重复计数）；
- 覆盖结论受限于缺少逐盘证据，不能作为"每块盘均已被压测"的证明；
- 未采集 SMART / 内核日志 / 文件系统校验，不构成硬盘健康结论。

## 7. 问题与建议

| 问题 | 建议 |
|---|---|
| 首个任务比其余早 7 分钟启动，实际形成两个启动批 | 统一启动间隔，或在配置中记录批次归属 |
| 日志名为循环序号，无法逐盘反查 | 记录测试目录，日志按挂载点命名 |
| 内存峰值仅达设计值 82% | 按机型计算内存目标，或采用保持型分配 |
| 监控为整机汇总 | 增加按设备统计 |
