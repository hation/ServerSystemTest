### 4.2 内存

| 项目 | 数值 |
|---|---|
| 内存条 | 16 根 × 64 GiB = 1024 GiB |
| 单 worker 推导 | 64G − max(6G, 64G/8=8G) = **56G** |
| 内存目标 | 16 × 56G = **896 GiB** |
| 上限 1（模块 88%） | 1024 × 88% = 901G |
| 上限 2（MemTotal 92%） | 995 × 92% = 915G |
| 上限 3（磁盘预留） | 不生效 |
| 分配上限（取最小） | **901G** |
| 需求 vs 上限 | 896G < 901G → **未超限** |
| 内存占比 | 896G / 995G = **90.05%** |

判定：分配逻辑合规（单根扣除预留、两道上限取最小），`run-config` 明确记录“未超限”。**但注意**：本机为 1TB 级（16×64G），按推导得到的目标占 MemTotal 的 90%，比一般机型（82% 设计约定）更高，可用内存仅约 94–99 GiB；这与上限只差 5G，10h 长稳下余量偏紧。
