# 服务器综合压力测试报告（7380 · stress-test-6-1）

| 项目 | 内容 |
|---|---|
| 报告编号 | STRESS-7380-ST6-1-20261114 |
| 设备标识 | stress-test-6-1（数据目录 `tmp/stress-test-6-1`） |
| 测试机型 | Hygon C86-3G 7380 32-core（2 路，128 逻辑线程） |
| 测试类型 | CPU / 内存 / 磁盘 组合负载长稳测试 |
| 测试时间 | 2026-11-14 14:24:54 — 2026-11-15 00:28:35（10 小时） |
| 内存总量 | 1,120.7 GiB |
| 结论 | **有条件通过（OK_LIMITED）**：稳定性通过；仅 1 块数据盘却并发 6 个磁盘任务（超测） |

## 1. 测试目的

验证该机在 CPU、内存、数据盘与系统盘同时加压条件下连续运行 10 小时的稳定性。

## 2. 测试环境

| 项目 | 配置 |
|---|---|
| 机型 | 7380（Hygon C86-3G 32-core） |
| 内存 | 1,120.7 GiB |
| 系统盘 | `/dev/mapper/klas-root`，**7.4 TB**，挂载 `/`（本机系统盘容量与其他 7380 机型不同） |
| 数据盘 | **1 块**：`/dev/nvme0n1`，7.0 TB，挂载 `/mnt/HDD01` |
| 测试前占用 | 系统盘 61G（1%）；数据盘 28K（1%） |

## 3. 测试方法

共 9 个任务、分两批启动，均运行 10 小时且相互重叠：

| 批 | 启动时间 | 任务构成 |
|---|---|---|
| 第一批 | 14:24:54 — 14:25:25 | 2 个数据盘任务 + 1 个系统盘任务 + cpu + mem |
| 第二批 | 14:28:05 — 14:28:18 | 4 个数据盘任务 |

| 负载 | 命令 | 目标 |
|---|---|---|
| 磁盘合计 6 个数据盘任务 | `stress --hdd 1 --hdd-bytes 10G --timeout 10h` | 均指向唯一数据盘 `/mnt/HDD01` |
| 磁盘 1 个 | 同上 | 系统盘 `/stresstest-hdd` |
| CPU | `stress --cpu 110 --timeout 10h` | 110 线程 |
| 内存 | `stress --vm 16 --vm-bytes 54G --timeout 10h` | 目标 864G |

## 4. 测试结果

### 4.1 执行结果

| 项目 | 结果 |
|---|---|
| 批次目录 | 9 个（7 个 hdd + 1 cpu + 1 mem） |
| 采样行数 | 每批次 1191 行 |
| 退出码 | 9/9 为 `0` |
| 收尾行 | 9/9 有 `successful run completed` 级记录 |
| 错误日志 | 仅收尾结论行，无报错正文 |

### 4.2 资源指标（整机口径）

| 指标 | 实测 | 判定 |
|---|---|---|
| CPU 使用率 | 99.5% — 100.0% | 达标 |
| 内存峰值 | **699 GB**（目标 864G 的 80.9%） | 达标（≥691G） |
| swap | 全程 0 | 达标 |
| 整机写吞吐均值 | 1779 — 1781 MB/s | — |
| 写为 0 的窗口 | 0 — 1 / 1191 | 达标 |

### 4.3 稳定性

9 个任务全部正常结束，无 stderr 输出、无 OOM、无 swap、无重启、无性能衰减。两批任务并行运行约 10 小时，未出现相互导致的异常退出。

### 4.4 磁盘覆盖

| 项目 | 结果 |
|---|---|
| 已挂载数据盘 | **1 块** |
| 数据盘任务数 | **6 个** |
| 系统盘任务 | 1 个 |
| 判定 | **超测**：同一块盘上并发 6 个写 10G 的任务 |

后果：该盘承受 6 倍并发写压力，整机写吞吐 1780 MB/s 是 6 个任务的叠加值，**不能作为该盘单任务顺序写性能**。从稳定性角度看，压力更大，结论偏保守。

另需说明：数据目录内两批任务启动间隔 159 秒（>120 秒阈值），按规则拆为两个会话，但二者时间区间重叠，指标为整机汇总，故统一按混合口径解读。

## 5. 测试结论

1. **稳定性：通过。** 组合负载 10 小时（含同盘 6 并发写），9 个任务全部正常结束，无故障。
2. **CPU：通过。** 99.5%~100%。
3. **内存：通过。** 峰值 699G（80.9%）。
4. **磁盘：通过（压力偏大）。** 写非零窗口 100%，但为 6 任务叠加。
5. **覆盖：超测。** 1 块数据盘被 6 个任务重复加压，虽未漏盘，但压力模型与"一盘一任务"不一致。

**综合判定：有条件通过（OK_LIMITED）。**

## 6. 适用范围

- 可表述："该机在整机满载 + 单盘 6 并发写条件下 10 小时稳定"；
- 不可表述："单盘顺序写性能达标"（6 任务叠加值）、"每块盘均单独验证"（本机仅 1 块数据盘且被重复加压）。

## 7. 问题与建议

| 问题 | 建议 |
|---|---|
| 1 块盘起 6 个磁盘任务 | 按实际挂载清单生成任务，一盘一任务 |
| 两批任务重叠，形成 2 个会话 | 明确会话边界，避免重复启动 |
| 系统盘 7.4T，与其他 7380 机型配置不同 | 在报告中单列配置差异，避免横向误比 |
| 监控为整机汇总 | 增加按设备统计 |
