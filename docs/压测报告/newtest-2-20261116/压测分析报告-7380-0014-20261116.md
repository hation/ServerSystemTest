## 3. 测试方法

同一容器内共 5 个批次，最早启动于 2026-11-15 12:46:18，各任务启动间隔 ≤91s（≤120s 归并阈值），全程并发运行，属**混合模式组合压力**。

| 批次目录 | 类型 | 命令 | 开始时间 | 超时 | 监控间隔 |
|---|---|---|---|---|---|
| 20261115-124618-hdd | hdd | `stress --hdd 1 --hdd-bytes 10G --timeout 10h` | 2026-11-15 12:46:18 | 36000s | 30s |
| 20261115-124642-hdd | hdd | `stress --hdd 1 --hdd-bytes 10G --timeout 10h` | 2026-11-15 12:46:42 | 36000s | 30s |
| 20261115-124705-hdd | hdd | `stress --hdd 1 --hdd-bytes 10G --timeout 10h` | 2026-11-15 12:47:05 | 36000s | 30s |
| 20261115-124731-cpu | cpu | `stress --cpu 110 --timeout 10h` | 2026-11-15 12:47:31 | 36000s | 30s |
| 20261115-124749-mem | mem | `stress --vm 16 --vm-bytes 54G --timeout 10h` | 2026-11-15 12:47:49 | 36000s | 30s |

判定闸门（依据 `docs/superpowers/specs/2026-11-14-stress-log-interpretation-design.md` v3）：

- **B 运行完整性**：逐任务核对退出码与收尾行；
- **C 指标口径**：会话内 cpu/mem/hdd 并发 → 混合模式，只允许整机聚合指标，单项指标标 `N/A(混合)`；
- **D 覆盖性**：数据盘任务数与已挂载数据盘数比对；数量相等时因缺少逐盘证据只能记“不可判定”；
- **E 观测有效性**：CPU 均值 ≥90%、内存峰值 ≥ 目标 864 GiB 的 80%（691.2 GiB）、整机写非零窗口 ≥70%。

内存目标按 `--vm 16 × 54G = 864 GiB` 计。

| 项目 | 结果 |
|---|---|
| 运行完整性 | 通过（10 小时跑满，退出码 0，收尾行齐全） |
| 负载达成 · CPU | 100.0%（门槛 ≥90%） |
| 负载达成 · 内存 | 峰值 648.8 GiB，目标的 75.1%（门槛 ≥80%，未达成） |
| 负载达成 · 磁盘 | 写非零窗口 99.9%（门槛 ≥70%）；整机写吞吐 307.2 MB/s |
| 覆盖 | 不可判定 |

按混合模式规则，结论固定表述为“**组合负载下整机稳定**”（以运行完整性、稳定性为准）；上表各项为负载达成度，不构成 CPU / 内存 / 磁盘的单项性能结论。

限制项：

- 内存峰值 648.8 GiB，为目标 864 GiB 的 75.1%，低于 80% 门槛（691.2 GiB），差 42.4 GiB
- 数据盘无法逐盘对应，覆盖结论不能作为“每块盘均已压测”的证明

**综合判定：OK_LIMITED。**

## 6. 适用范围

- 仅说明“组合负载下整机稳定”，不代表 CPU / 内存 / 磁盘单项性能上限；
- 磁盘指标为整机 `/proc/diskstats` 汇总（含分区与 dm，可能重复计数），不代表单盘顺序写带宽；
- 内存指标口径为 `MemTotal − MemFree`，包含 page cache，非单一 stress 进程占用；
- 覆盖结论受限于缺少逐盘证据，不能作为“每块盘均已被压测”的证明；
- 未采集 SMART / 内核日志 / 文件系统校验，不构成硬盘健康结论。

## 7. 问题与建议

| 问题 | 建议 |
|---|---|
| 内存达成度 75.1%（目标 864 GiB） | stress 1.0.4 的 vm worker 分配后即释放，非保持型；建议改用保持型占用或提高单 worker 字节，并以 MemAvailable 下降幅度作为达成度口径 |
| 覆盖无法逐盘对应 | `run-config.txt` 记录 `--dirs`，日志按挂载点命名（如 stress-HDD01/HDD02/SYSDISK） |
| 监控为整机汇总 | 增加按设备（物理盘）维度的吞吐统计 |
| 无 OOM/内核事件留证 | 保留 `status.txt` 与 dmesg OOM 片段，便于回查 |

> 备注：本机挂载 2 块数据盘（/mnt/HDD01 与 /mnt/HDD02），数据盘任务 2 个、系统盘任务 1 个；两个数据盘批次的任务日志同名 stress-HDD01.log，无法逐盘对应（见 4.4）。
