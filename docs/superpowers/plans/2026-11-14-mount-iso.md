## 任务拆解

### Step 1: 新建 mount-iso.sh

文件：`offline-stress-pkg/mount-iso.sh`，按设计文档 3.1-3.6 实现：

- 头部注释：用法（四子命令）+ 测试接缝环境变量说明
- 环境变量默认值：DRY_RUN、SKIP_ROOT_CHECK、LSBLK_BIN、MOUNT_LOG（/root/stress-test/mount.log）、USB_MOUNT_POINT（/mnt/usb）、REPO_DEST（/opt/kylin-repo）、YUM_REPO_FILE（/etc/yum.repos.d/kylin-local.repo）、PKG_RPMS_DIR（脚本同目录 rpms/）、CREATEREPO_BIN（createrepo）
- 公共函数：`now()`、`usage()`、`root_check()`、`sys_disk_base()` / `is_sys_disk_or_part()`（复用 disk-mount.sh 的 df / 沿 lsblk 树向上解析逻辑）、`log_cmd()`（写 MOUNT_LOG）
- `usb_disk()`：lsblk 过滤 TYPE=disk && TRAN=usb，排除系统盘，返回第一个 USB 盘名
- `usb_first_part()`：查该盘第一个 part 子项（无分区则返回整盘名）
- `usb_is_mounted()`：检查 $USB_MOUNT_POINT 是否已挂载（df -P 或 findmnt）
- `mount_usb()`：mkdir -p $USB_MOUNT_POINT + mount 设备到挂载点（已挂载跳过）
- `find_repodata_dir()`：find $USB_MOUNT_POINT -maxdepth 3 -type d -name repodata，输出父目录列表；多个提示取第一个
- `find_rpm_dir()`：给定目录含 *.rpm 返回真
- `copy_dir_into()`：源目录复制到目标（mkdir -p + cp -r 源/. 目标/），目标已存在非空时交互询问覆盖合并（y）/跳过
- `write_repo_file()`：写 $YUM_REPO_FILE（baseurl=file://$REPO_DEST；已存在提示跳过不覆盖）
- `cmd_build()`：root_check → RPM 定位（U盘已挂载且含 *.rpm → 用之；否则 --rpm-dir；否则 $PKG_RPMS_DIR）→ createrepo（$CREATEREPO_BIN --update <RPM目录>；命令不存在提示安装 createrepo/createrepo_c 并退出 1；DRY_RUN 只打印）→ 落盘 $REPO_DEST（copy_dir_into）→ U盘已挂载则写 $USB_MOUNT_POINT/kylin-repo（copy_dir_into），未挂载提示可后续 mount 拷贝 → 提示完成
- `cmd_mount()`：root_check → mount_usb（无 USB 盘提示手动指引退出 1）→ find_repodata_dir（无则提示退出 1）→ copy_dir_into 源到 $REPO_DEST → write_repo_file → 验证 ls $REPO_DEST | head + yum repolist（失败仅提示）
- `cmd_status()`：输出 U 盘挂载点/设备、$REPO_DEST 存在性+条目数+含 repodata 与否、repo 文件存在性+baseurl、日志路径
- `cmd_umount()`：root_check → 列出 $USB_MOUNT_POINT（已挂载）→ y 确认 → umount；不删 $REPO_DEST/$YUM_REPO_FILE，提示手动清理命令；DRY_RUN 只打印
- 子命令分发：build/mount/status/umount

注意：DRY_RUN=1 时所有写操作（mount、createrepo、cp、写 repo 文件、umount）只打印不执行；交互确认在 DRY_RUN 下跳过（直接打印计划）。
